\section{Introduction}
A set of n-vectors $\vec v_1, \vec v_2, \cdots , \vec v_n$ are linearly independent if the only solution to $c_1\vec v_1 + c_2 \vec v_2 + \cdots + c_n\vec v_n$ is zero, and $c_1 = c_2 = \cdots = c_n = 0$ where $c_i \in \mathbb{R}$. If any $c_i  \neq 0$, then the vectors are \textit{linearly dependent}. In machine learning, dependent vectors carry redundant information. This causes multicollinearity, rendering the model weights unstable.\\[0.15in]
A basis is the minimum set of vectors that are linearly independent and span the entire space, meaning the vectors can reach every point in space. The number of basis vectors are equal to the TRUE \textit{dimensionality} of a dataset.
\section{Formal Definitions}

\subsection{Linear Independence}
Linear independence holds if:
\[
c_1 \vec v_1 + c_2 \vec v_2 + \cdots + c_n \vec v_n = \vec 0
\]

where; 
\[
c_1 = c_2 = c_3 = \cdots = c_n = 0
\]

If $c_i \neq 0$, then the set of vectors is said to be linearly dependent.\\[0.15in]
\textbf{Possible Outcomes}
\begin{enumerate}
\item Linear independence - Each vector add a genuine new information
\item Linear dependence - Redundant vector(s) present, causes multicollinearity.
\end{enumerate}
\subsection{Basis}
For a set of vectors to be a basis vector the following two properties must hold:
\begin{enumerate}
\item Vectors must be linearly independent
\item Span the entire space. The vectors must reach every point in that space
\end{enumerate}

\subsection{Standard Basis}
There are standard basis in every space, e.g. 
\[
\text{Standard basis in }
\mathbb{R}^2
\rightarrow
\left\{
\begin{pmatrix}
1\\0
\end{pmatrix}, 
\begin{pmatrix}
0 \\1
\end{pmatrix}
\right\}
\]

\[
\text{Standard basis in }
\mathbb{R}^3
\rightarrow
\left\{
\begin{pmatrix}
1 \\0 \\0
\end{pmatrix},
\begin{pmatrix}
0\\1\\0
\end{pmatrix},
\begin{pmatrix}
0\\0\\1
\end{pmatrix}
\right\}
\]

\[
\text{Standard basis in }
\mathbb{R}^n
\rightarrow
\left\{
\begin{pmatrix}
1\\0\\ \vdots \\0
\end{pmatrix},
\begin{pmatrix}
0\\1\\ \vdots \\ 0
\end{pmatrix},
\begin{pmatrix}
0\\0\\ \vdots \\ 1
\end{pmatrix}
\right\}
\]
\section{Proof: A Set Containing the Zero Vector is Always Linearly Dependent}
We want to prove that a set of n-vectors $S = \{\vec 0,\vec  v_1, \vec v_2, \vec v_3, \cdots, \vec v_n \}$ is linearly dependent because it contains the zero vector. For a linearly independent set of vectors, the linear combination is $c_0 \vec v_0 + c_1 \vec v_1 + c_2 \vec v_2 + \cdots c_n \vec v_n = \vec 0$.\\[0.15in]
Let $c_0 = 1$, $v_i \in S$ and $c_i \in \mathbb{R}$\\[0.15in]
Then; 
\[
	1\cdot \vec 0 + 0 \cdot \vec v_1 + 0 \cdot \vec v_2 + \cdots + 0 \cdot \vec v_n = \vec 0
\]
The above equation shows that  there exist $c_i$'s that are not all zeros. In conclusion, $\{\vec 0, \vec v_1, \cdots , \vec v_n\}$ is a linearly dependent set.

Vectors $v_3 = (2, 4)$ and $v_4 = (1, 2)$ are linearly dependent with rank = 1. This means that atleast one of the vectors is redundant.
\subsection{Standard Basis Verification}
The rank for standard basis in $\mathbb{R}^2$ is $2$, while in $\mathbb{R}^3$ is $3$. This means that with standard basis vectors, you can reach every point in a vector space.

\subsection{ML Connection — Feature Matrix}
The feature matrix $X = \begin{pmatrix}

\end{pmatrix}

\section{ML Connection}
Before training a model, check for redundant features. Redundant features add no new information  causing multicollinearity, which makes a model weights to be unstable.
