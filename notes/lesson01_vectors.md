\# Linear Algebra Mastery



\## Vectors

A vector is an ordered list of finite real numbers. There are different types of vectors. Some of them are:



1. Unit vector
2. Standard unit vector
3. Zero vector - A vector of all entries equal to zero.
4. Subvector - A portion of a vector. It is extracted using index. In maths index starts from 1, not 0.
5. Ones vector - A vector with only 1. Written as 1, or more precisely $1\_n$.
6. Scarce vector - A vector with many zero coefficients. Non-zero coefficients are written as \*\*nnz(x)\*\*, where x is a n-dimension vector.
